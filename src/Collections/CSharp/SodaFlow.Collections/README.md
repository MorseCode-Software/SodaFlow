# SodaFlow.Collections

Large keyed collections for SodaFlow in C#, where each observer can watch one item without waking
for every edit. Install it with SodaFlow when you have such a collection. It pulls in
SodaFlow.Collections.Core, and it adds `Maybe<T>` to the answers of the core.

```bash
dotnet add package SodaFlow.Collections
```
