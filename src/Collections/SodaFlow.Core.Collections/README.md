# SodaFlow.Collections.Core

The shared core of SodaFlow.Collections and SodaFlow.FSharp.Collections. Don't reference it
directly. Install SodaFlow.Collections for C# or SodaFlow.FSharp.Collections for F#, which depend
on it.
