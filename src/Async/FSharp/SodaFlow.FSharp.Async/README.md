# SodaFlow.FSharp.Async

Runs `Task`-based work from a SodaFlow stream in F#. Install it with SodaFlow.FSharp only if you
need that. It pulls in SodaFlow.Async.Core.

```bash
dotnet add package SodaFlow.FSharp.Async
```
