# SodaFlow.Core

The engine of SodaFlow, a functional reactive programming library for .NET. It declares the types
you hold, such as `Stream<T>`, `Cell<T>`, `Behavior<T>`, and `Transaction`, with the machinery
that makes updates atomic. It has no usable operations of its own.

Don't reference it directly. Install SodaFlow for C# or SodaFlow.FSharp for F#, which depend on
it.
