# SodaFlow.Bindable.ObjectModel.Core

The shared core of SodaFlow.Bindable.ObjectModel and SodaFlow.FSharp.Bindable.ObjectModel. Don't
reference it directly. Install SodaFlow.Bindable.ObjectModel for C# or
SodaFlow.FSharp.Bindable.ObjectModel for F#, which depend on it.
